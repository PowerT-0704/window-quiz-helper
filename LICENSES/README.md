# 上游许可文本

以下标准许可文本来自对应上游源码仓库；文件名标明适用的许可版本。构建脚本还会把当前构建环境实际附带的 Python、PySide6、Shiboken6 和 PyInstaller 许可文件复制到便携包中。

- Qt：<https://code.qt.io/cgit/qt/qtbase.git/tree/LICENSES?h=6.12>
- PySide：<https://code.qt.io/cgit/pyside/pyside-setup.git/tree/LICENSES?h=6.12>
- FFmpeg：<https://ffmpeg.org/legal.html>

各组件的版权声明、许可选择及额外第三方声明以对应组件发行版和上游文档为准；附带一个许可文本不表示所有组件都使用同一种许可。详见项目根目录 THIRD_PARTY_NOTICES.md。
