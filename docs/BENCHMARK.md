# v0.2.2 稳定性与耗时基线

日期：2026-11-03。Windows 本机测试，自有 Qt 目标与本地 Mock 接口；未使用真实 Key、用户窗口或在线 AI。

## 悬停与层级

旧逻辑：20 次悬停刷新触发 20 次 `SetWindowPos`，即使位置不变。

最终 60.05 秒测试包含 551 次鼠标位置切换，覆盖目标、悬浮窗空白和按钮：

| 指标 | 次数 |
|---|---:|
| 原生层级写入 | 0 |
| Show／Hide | 0／0 |
| Move／WinIdChange | 0／0 |
| 前台焦点变化 | 0 |

被置顶目标重新覆盖、隐藏和原生最小化后的找回另行验证通过。自动层级恢复至少间隔 500 毫秒，主动找回可立即执行。

开发期间首轮长测曾观察到一次恢复，第二轮因面板隐藏中断，尚未确定外部触发原因；在加入触发状态跟踪、单独运行后，最终完整长测通过。该证据不能替代实际手机投屏软件的验收。

## 同一题区十次强制查询

真实 WGC 捕获自有静态题目窗口，PNG、原始清晰度、每次强制发起独立请求。本地 Mock 服务人为等待 15 毫秒；P95 使用最近秩法。所有十次均未使用缓存。

| 阶段 | 中位数（ms） | P95（ms） |
|---|---:|---:|
| 捕获 | 439.87 | 490.54 |
| 裁剪与编码（含线程排队） | 13.43 | 15.33 |
| 请求准备 | 3.75 | 5.03 |
| 接口响应 | 19.21 | 19.71 |
| 总耗时 | 493.18 | 530.94 |

总耗时还包含完成登记和界面状态更新，不等于分阶段值之和。接口响应包括网络、Mock 处理和响应解析；不代表 DeepSeek 或其他真实模型延迟。

本轮明确收益是消除稳定状态的重复窗口写入。捕获仍为本地闭环主要耗时，暂不以压缩图片、削减提示词或改变思考设置换取未经验证的收益。

.\.venv\Scripts\python.exe -u scripts\overlay_smoke.py
